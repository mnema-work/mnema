- **`mnema doctor --latest` asks npm which version is the newest, checks it, and says how to install it.** It is the one request `doctor` makes, only when typed: two public GETs to `registry.npmjs.org` (the newest version's document, then, if it is newer than yours, its attestations), each ended within 5 seconds, bounded, with no redirect, naming only the package and never your version, project or path; it writes nothing and takes no `--json`, mirror or `.npmrc`. A version is named as one to install, with an exact command for how `mnema` was installed (`npm i -g`, with or without `--prefix`, or `pnpm add -g`), only after its npm provenance verifies offline against the Sigstore trust root the binary carries, with four comparisons the library does not make (the certificate names this project's release workflow, the statement names this package and version, its digest is the one npm gave, and the workflow ran in this repository), and two days after the time its signature was logged. A version without attested provenance is said to exist, with no command, and so is one whose provenance does not hold. The line reports what npm.org lists, never what your own registry serves, and a terminal does not prove a person is at it: the text says a person decides and an agent does not update on its own. Nothing checks on its own: no daily request, no switch, no line at other verbs yet.
