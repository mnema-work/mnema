Added

- **`mnema upgrade` removes the mnema MCP server where it is declared a second time.** In your own `~/.claude.json`
  the entry goes when the server is declared anywhere else the host reads (a plugin, the project's files), by cutting
  its bytes only, after a copy of the file is kept beside it; a file the edit cannot read safely is refused with the
  reason and nothing is written. The entry of the project's committed `.mcp.json` is asked, and only beside an
  installed plugin. Entries of other projects are not touched.
